# Ohm's Law Calculator:
A command-line Python programme that solves for voltage, current or resistance when you give it the other two values.

## Features:
Choose what to solve for: V, I or R (upper or lower case)  
Accepts a decimal point or a comma (1.5 or 1,5)  
Rejects text, zero and negative values, then asks again  
Shows the formula used and the answer to 2 decimal places  

## Formulas:
-V = I × R  
-I = V / R  
-R = V / I  

## How to run:
1. Install Python 3 from python.org  
2. Download ohms_law_calculator.py  
3. In a terminal, run: python ohms_law_calculator.py  

## Example run:
What do you want to solve for between V, I, and R? V  
Enter current: 2  
Enter resistance: 5  
Formula: V = I*R  
Calculated voltage: 10.00 V  

## Limitations:
Version 1 only accepts values above 0 (a deliberate simplification)
